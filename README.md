# infobolsa-posts

Posts automáticos do Instagram @infobolsainvestimentos.

- `ROTINA.md`: fechamento de mercado, dias úteis às 18h30.
- `ROTINA-noticia.md`: post escuro de notícia, todos os dias às 12h.
- `kit/`: geradores (`gen_fechamento.py`, `gen_escuro.py`), `render.py`, fontes, logos e fotos de fundo (com créditos em `kit/assets/fundos/creditos.json`).
- `posts/`: imagens publicadas (o Instagram lê daqui pelo link raw).
